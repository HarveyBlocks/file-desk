# Application icon

The mark uses Lucide's FolderOpen geometry with a transparent background, blue outline, warm gold rear layer and cyan-to-blue front layer. The colored outline stays visible on light and dark backgrounds.

From Web, run npm run icons to regenerate file-desk.png, the multi-resolution file-desk.ico and the matching Next.js favicon. The generator renders every ICO size from the original vector. Generated sizes are 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixels.

The Windows executable, WPF windows, tray and browser tab share this artwork. Lucide and Feather notices are retained in LICENSE-lucide.txt.
